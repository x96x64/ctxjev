# Incident INC-2291: warehouse API overload (2026-09-17)

## Summary

At 03:12 UTC the warehouse API started returning 503 during a deploy. inventory-sync retried every failed request forever at a fixed 100ms, from all 12 pods, which kept the API saturated for 41 minutes after the deploy finished. Requests that failed with 400 (a bad SKU filter) were also retried forever.
